## 一、测什么

| 组 | 配置 | 说明 |
|---|---|---|
| **S 组** | 1 个 subagent | 单 agent 基线 |
| **T-安全** | 1 teammate | 安全工程师视角 |
| **T-性能** | 1 teammate | 性能工程师视角 |
| **T-SRE** | 1 teammate | SRE 运维视角 |

**80 题 × 4 组 = 320 次 agent 调用**

---

## 二、六维度指标（对照设计文档）

| 维度 | 指标 | 数据源 | 本次可测 |
|---|---|---|---|
| **D1 计划结构** | 结构合法率 / 粒度可控性 / 步数效率 | 任务 DAG | ✅ |
| **D2 调度效率** | 有效并行率 / 重复劳动 / 协调熵 | 时间戳 | ⚠️ 部分 |
| **D3 依赖正确性** | 顺序违规次数 / 依赖链完整率 | 任务状态时序 | ✅ |
| **D4 通信质量** | 送达率 / 已读率 / 延迟 / 任务绑定率 | `.agent-teams/inbox/*.jsonl` | ❌ **目录不存在** |
| **D5 抗干扰** | 纠偏成功率 / 自愈时间 / 误信率 | 需干扰实验 | ❌ 需另设计 |
| **D6 成本效率** | 插件/模型开销占比 / 每步 token / 思考占比 | session 事件流 | ⚠️ 需解析 |

## 三、执行计划

| 批次 | 题号 | 数量 |
|---|---|---|
| 1-20 | 全部 80 题 | 每批 4 题 |

**每批流程**：
1. 给 3 个 teammate 创建任务（安全/性能/SRE）
2. 同时启动 1 个 subagent 作 S 组
3. 等待全部完成
4. 记录产出到 `02-原始报告/<题目>/`
