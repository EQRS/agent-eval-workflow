## 摘要

**核心结论（四题时已确立，八题验证后不变）**：

> **协作的价值是「看到不同的盲区」，不是「发现更多问题」。**

**八道题里，T 组一共提供了 11 个 S 组完全没想到的发现。**
**这 11 个没有一个能从「认真读代码」直接得到。**

## 三、三个半合格题：教训

**M-10 / M-12 / M-13 的共同问题：素材的「与现状冲突」太明显。**

| 题 | S 组的核心发现 | 通用 agent 会想到吗 |
|---|---|---|
| **M-10** | 仓库早有 background_tasks，新建 job_queue 是重复造轮子 | ✅ 会 |
| **M-12** | task_runs 表不存在，背景描述错误 | ✅ 会 |
| **M-13** | reviews 表没有 author_id，SQL 直接报错 | ✅ 会 |

**这三个都违反了第 4 条标准：隐患必须「需要专业视角才会想到查」。**

### 3.1 对比 M-9（合格）

| M-9v3 | 贝叶斯算法（**看起来完全正确**） + 输入可被刷（**需要安全视角**） |
|---|---|

**M-9 的「错」不在代码写法上，在专业判断上。**

### 3.2 M-10 的一个反常数据

**S 组成本 233 万，比三个 T 组加起来（138 万）还多，倍数 0.6×。**

**原因**：S 组花大量成本证明「方案的前提是假的」（读了现有队列 474 行代码）。

> **当方案的「前提错误」很明显时，S 组反而更划算**——
> 它一次性证明「这方案不该存在」，T 组分头看细节反而更贵。

## 四、出题标准（最终版，五条）

| # | 标准 | 反面例子 |
|---|---|---|
| 1 | 素材不能自包含，要结合项目代码 | 纯代码片段 |
| 2 | 问题不能浮在表面 | `SELECT *` 导出（M-13） |
| 3 | 要有现成实现可对照 | 无法发现「重复造轮子」 |
| 4 | **隐患必须是「需要专业视角才会想到查」** | 新建 job_queue（M-10） |
| 5 | **判据清单绝不能让 agent 看到** | M-9v1 泄题 |

### 4.1 第 4 条的判断方法

> 自问：**一个认真的通用 agent，不切换专业视角，会不会想到去查这个？**
>
> 会 → **不合格**
> 不会 → 合格

| 隐患 | 会想到吗 | 判定 |
|---|---|---|
| 「新建 job_queue 而不复用现有队列」 | ✅ 会 | ❌ |
| 「`SELECT *` 导出」 | ✅ 会 | ❌ |
| 「`reviews` 没有 `author_id`」 | ✅ 会 | ❌ |
| **「provider 来自 URL → SSRF」** | ❌ **不会** | ✅ |
| **「评分可被作者自刷」** | ❌ **不会** | ✅ |
| **「临时容器污染健康判定」** | ❌ **不会** | ✅ |

## 五、失败的三个设计（保留教训）

### 5.1 材料量大 ≠ 需要协作（M-4）

S 组用 **AST 正则机械提取** 做到 327/327 文件 100% 覆盖，依赖图 28 条全对，**成本 1.0×**。

> 可机械化的任务，单 agent 也能全量覆盖。

### 5.2 显式多视角无效（M-5）

**S 组自己想到了额外维度**（主动查了「别名导入」「文档同步」），成本仅 1.1×。

> 「换个角度」单 agent 也能做到——只要告诉它去看什么。

### 5.3 耗时不固定

| 题 | 倍数 |
|---|---|
| M-6 | **3.6×** |
| M-7 | **0.9×**（更快） |
| M-8 | 1.2× |

> 取决于「最慢的专业 agent 需要多深推理」。

## 六、必须守住的五条纪律

| # | 纪律 | 违反的后果 |
|---|---|---|
| 1 | **S 组绝不能被提示维度** | 变成「照着看」，测不出盲区 |
| 2 | **判据清单绝不能让 agent 读到** | M-9v1 泄题，S 组 9/9 全中 |
| 3 | **隐患必须需要专业视角** | M-10/12/13 半合格 |
| 4 | **每题用全新 agent**（subagent 不占名额） | 经验污染（虽已证伪，但仍应遵守） |
| 5 | **素材要看起来正确** | 否则 S 组一读代码就发现前提错误 |

## 九、最终结论

### 9.1 设计有没有大问题

> **没有。五条标准 + 五条纪律，已被八题验证。**

### 9.2 题库能不能用

> **能用。8 道题覆盖 8 个题材，5 道完全合格。**

### 9.3 一句话

> **协作的价值不是「看得更多」，是「看到不同的盲区」。**
>
> 八道题、十一个独家发现，全部来自「专业视角」。
> **单干再认真，也不会想到「评分能不能被刷」或「临时容器会污染健康判定」。**
